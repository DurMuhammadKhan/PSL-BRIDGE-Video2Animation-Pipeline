# Your character goes here

Put **one** rigged character file in this folder (`.glb`, `.gltf` or `.fbx`,
with a skeleton), e.g. `Ali.glb`. Stages 3 and 4 retarget every animation onto
it and name their outputs after it (`output/Ali_animations.glb`).

Bone mapping and other settings are in `config.py` — see "Add your character"
in the main README. Model files in this folder are not committed to git.
